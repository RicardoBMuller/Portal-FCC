# Portal FCC — V15.3

Portal web estático para GitHub Pages com Supabase Auth/Google, projetos, participantes, diretórios, OCR.Space, salas e checklist.

## Novidades V15.3

- **Calculadora do tempo de prova sem login**: disponível diretamente na tela de acesso.
- **Encerrar projeto**: criador ou PO pode tornar o projeto somente leitura.
- **Excluir projeto**: apenas o criador pode excluir definitivamente o projeto e seus dados relacionados.
- Projetos encerrados continuam disponíveis para consulta e aparecem identificados na listagem.

Para atualizar uma instalação V15.2 existente, execute apenas `SUPABASE_HOTFIX_V15_3.sql` no SQL Editor do Supabase e depois publique os novos arquivos no GitHub Pages.
